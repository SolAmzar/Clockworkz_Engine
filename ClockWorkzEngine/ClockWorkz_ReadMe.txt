Game Concept:
Top-down psychological horror where everyday spaces—HDB corridors, MRT rides, exam halls, and offices—twist into nightmares filled with phantoms. Players survive by hiding, evading, and managing limited light while collecting memory fragments to uncover the truth.

Custom Demo Usage:
The 'W', 'S', up and down arrow keys can be used to navigate the menu. The 'exit game' exits the game.
